# Climate Change Modeling & Sentiment Analysis Using Machine Learning

## Project Overview
This project focuses on analyzing climate change data and public sentiment using machine learning and Natural Language Processing (NLP). The dataset is based on user comments collected from NASA’s social media posts related to climate change.

---

##  Objectives
- Analyze public opinion on climate change
- Perform sentiment analysis on user comments
- Visualize trends and insights
- Apply machine learning techniques for prediction

---

##  Dataset
- Source: NASA Climate Change Facebook Page
- Data includes:
  - Date
  - Likes Count
  - Comments Count
  - User Comments (Text)

---

##  Technologies Used
- Python 
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- NLP (TextBlob / NLTK)

---

## Features
- Data Cleaning & Preprocessing
- Sentiment Analysis (Positive / Negative / Neutral)
- Data Visualization
- Trend Analysis

---

## Output
- Graphs showing sentiment distribution
- Insights on public opinion
- Analysis of engagement vs sentiment
